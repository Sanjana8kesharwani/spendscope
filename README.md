# SpendScope

SpendScope is an AI spend auditing platform that helps startups and engineering teams analyze their AI tool spending, identify unnecessary costs, and discover potential monthly and annual savings opportunities.

The platform generates instant AI spend audits, provides personalized optimization recommendations, and allows users to share public audit reports.

## Live Demo

https://spendscope-six.vercel.app/

## Features

- AI spend audit generation
- Multi-tool support
- Personalized AI-generated summaries
- Public shareable audit reports
- Audit history dashboard
- Lead capture integration
- Responsive UI
- Supabase backend integration

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
