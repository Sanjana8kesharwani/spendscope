# User Interviews

## Interview 1

Role: Startup Founder

Quotes:
- "AI costs are becoming unpredictable."
- "We don't know whether we're overpaying."
- "A benchmarking tool would help."

Biggest insight:
Founders want quick optimization suggestions, not complex analytics.

## Interview 2

Role: Freelance Developer

Quotes:
- "I subscribe to too many AI tools."
- "I forget which tools I actually use."
- "Cost visibility matters."

Biggest insight:
Users want spending visibility more than detailed finance reports.

## Interview 3

Role: Engineering Student / Side Project Builder

Quotes:
- "I try multiple AI tools every month."
- "Pricing changes are confusing."
- "A comparison tool would save time."

Biggest insight:
Tool switching behavior is very common among smaller builders.
